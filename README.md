# ebook_scanner

전자책 뷰어에 표시된 페이지 영역을 자동으로 캡처하고, 캡처한 이미지를 하나의 PDF 파일로 만들어주는 Windows용 데스크톱 프로그램입니다.

![ebook_scanner 실행 화면](gui_image_win.png)

## 무엇을 하나요?

`ebook_scanner`는 전자책 뷰어 자체에서 PDF 저장 기능을 제공하지 않을 때 사용할 수 있는 화면 캡처 기반 PDF 생성 도구입니다. 사용자가 캡처할 영역, 페이지 수, 페이지 넘김 키, 저장 위치를 지정하면 프로그램이 페이지를 넘기며 이미지를 저장하고 마지막에 PDF로 변환합니다.

## 주요 기능

- 마우스 클릭으로 캡처 영역 좌측상단/우측하단 좌표 지정
- 총 페이지 수, PDF 이름, 저장 폴더 입력
- 캡처 간격과 시작 대기 시간 조절
- 오른쪽/왼쪽/위/아래/스페이스/Page Down 페이지 넘김 키 지원
- 시작 전 전자책 뷰어 포커스 자동 클릭
- 캡처 진행률과 PDF 변환 진행률 표시
- 작업 중지 버튼
- PDF 생성 후 원본 캡처 이미지 삭제 또는 보관 선택
- 기존 PDF 파일 덮어쓰기 확인
- Windows에서 사용할 수 없는 파일명 문자 자동 정리
- GUI가 멈추지 않도록 백그라운드에서 캡처 및 변환 실행

## 요구 사항

- Windows 데스크톱 환경
- Python 3.10 이상
- 화면 캡처와 키보드/마우스 제어 권한

## 설치

```powershell
git clone https://github.com/deploy103/ebook_scanner.git
cd ebook_scanner

python -m venv .venv
.\.venv\Scripts\activate

pip install -e .
```

## 실행

설치 후 실행:

```powershell
ebook-to-pdf
```

소스에서 직접 실행:

```powershell
python -m ebook_to_pdf
```

## 사용 방법

1. 전자책 뷰어를 열고 첫 페이지가 보이도록 준비합니다.
2. `좌측상단 좌표 클릭`을 누르고 캡처할 영역의 왼쪽 위 모서리를 클릭합니다.
3. `우측하단 좌표 클릭`을 누르고 캡처할 영역의 오른쪽 아래 모서리를 클릭합니다.
4. `총 페이지 수`에 캡처할 페이지 개수를 입력합니다.
5. `PDF 이름`과 `저장 폴더`를 지정합니다.
6. 전자책 뷰어에서 다음 페이지로 이동하는 키를 `페이지 넘김 키`에서 선택합니다.
7. 페이지 로딩이 느리면 `캡처 간격`을 늘립니다.
8. `PDF로 만들기`를 누르고 완료 메시지가 나올 때까지 기다립니다.

## 설정 안내

| 항목 | 설명 |
| --- | --- |
| 좌측상단 좌표 | 캡처 영역의 왼쪽 위 기준점입니다. |
| 우측하단 좌표 | 캡처 영역의 오른쪽 아래 기준점입니다. |
| 총 페이지 수 | 자동으로 캡처할 페이지 개수입니다. |
| PDF 이름 | 생성할 PDF 파일 이름입니다. `.pdf`는 자동으로 처리됩니다. |
| 저장 폴더 | PDF와 임시 캡처 이미지가 저장될 위치입니다. |
| 캡처 간격 | 페이지 넘김 후 캡처 전까지 기다리는 시간입니다. |
| 시작 대기 | `PDF로 만들기`를 누른 뒤 첫 캡처 전까지 기다리는 시간입니다. |
| 페이지 넘김 키 | 전자책 뷰어에서 다음 페이지로 이동할 때 사용할 키입니다. |
| 뷰어 포커스 | 시작 전에 캡처 영역을 클릭해 전자책 뷰어를 활성화합니다. |
| 캡처 이미지 보관 | PDF 생성 후 PNG 원본 이미지를 삭제하지 않고 남깁니다. |

## 사용 시 주의사항

- 프로그램 창이 캡처 영역을 가리지 않도록 옆으로 옮긴 뒤 실행하세요.
- 선택한 페이지 넘김 키가 전자책 뷰어에서 실제로 동작해야 합니다.
- 페이지 렌더링이 느린 뷰어에서는 캡처 간격을 충분히 늘려야 누락이나 중복 캡처를 줄일 수 있습니다.
- 페이지 수가 많으면 PDF 생성 시간이 길어지고 파일 크기가 커질 수 있습니다.
- 본인이 열람하거나 백업할 권한이 있는 문서에만 사용하세요.
